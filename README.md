# Nosso Caixa

Dashboard financeiro compartilhado para controle de receitas, despesas, orçamento e metas.

## Desenvolvimento

```bash
npm install
npm run dev
```

O Vite exibirá o endereço local, normalmente `http://localhost:5173`.

## Verificações

```bash
npm run lint
npm run build
```

## Estado atual

O aplicativo usa Supabase Auth para acesso das duas pessoas e PostgreSQL para armazenar os lançamentos compartilhados.

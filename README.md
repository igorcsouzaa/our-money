# 💰 Nosso Caixa

O **Nosso Caixa** é um sistema moderno de gerenciamento e controle financeiro desenvolvido para facilitar a organização das finanças (seja de forma individual, para casais ou pequenos grupos). Com ele, é possível monitorar entradas, saídas, definir metas e acompanhar relatórios claros sobre a saúde financeira.

---

## 🚀 Funcionalidades

- **Dashboard Geral:** Visão clara do saldo atual, receitas do mês e despesas acumuladas.
- **Gerenciamento de Transações:** Cadastro, edição e exclusão de receitas e despesas.
- **Categorização Inteligente:** Separação de gastos por categorias (Ex: Alimentação, Moradia, Lazer, Investimentos).
- **Metas de Economia:** Definição de objetivos financeiros com barras de progresso.
- **Gráficos Interativos:** Relatórios visuais para entender facilmente para onde o seu dinheiro está indo.

## 📦 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina as seguintes ferramentas:
- [Git](https://git-scm.com)
- [Node.js](https://nodejs.orgen/) (ou o gerenciador/ambiente correspondente ao seu projeto)

### 🔧 Passo a Passo

```bash
# 1. Clone este repositório
\$ git clone https://github.com

# 2. Acesse a pasta do projeto
\$ cd our-money

# 3. Instale as dependências
\$ npm install # ou yarn install / pnpm install

# 4. Configure as variáveis de ambiente (se houver)
# Crie um arquivo .env na raiz do projeto e preencha as chaves conforme o .env.example
\$ cp .env.example .env

# 5. Execute a aplicação em modo de desenvolvimento
\$ npm run dev # ou o comando configurado no seu package.json
```
